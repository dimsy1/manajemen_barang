# Sistem Manajemen Barang

Aplikasi manajemen barang sederhana untuk tugas Sertifikasi Kompetensi (Serkom).

## Fitur Utama
- CRUD (Create, Read, Update, Delete) Data Barang.
- Validasi Input (Stok/Harga tidak boleh negatif).
- Filter Pencarian & Pengurutan Data.
- Export Laporan ke PDF.

## Tech Stack
- **Frontend:** React + TypeScript + Vite.
- **Backend:** Node.js + Express + MySQL.
- **Documentation:** Swagger (OpenAPI).

## Cara Menjalankan
1. Clone repo: `git clone https://github.com/...`
2. Backend: `cd backend && npm install && npm run dev`
3. Frontend: `cd frontend && npm install && npm run dev`
4. Setup database: Import file `db_manajemen_data_produk.sql` ke MySQL.
